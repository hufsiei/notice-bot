# 훕스 공지비서 (프로토타입)

한국외대 홈페이지의 일반·학사·장학·채용 공지와 국제교류처 공지를 모아, 공지마다 **누구에게 / 무엇을 / 언제까지**를 뽑아 보여 주고 마감일을 캘린더(.ics)로 내보내는 웹페이지입니다. 2026 AI 캠퍼스 바이브코딩 경진대회 출품용으로 만들었습니다.

## 실행

```
python run.py              # 수집 → 추출 → 페이지 생성 (게시판마다 2페이지)
python run.py --pages 5    # 더 많이 수집
python run.py --no-collect # 수집 없이 페이지만 다시 만들기
```

결과물은 `site/` 폴더에 생깁니다. `site/index.html`을 브라우저로 열면 됩니다. 추가 설치는 필요 없고 Python 표준 라이브러리만 씁니다.

Windows에서는 `run.bat`를 작업 스케줄러에 등록해 하루 몇 번 돌리면 자동으로 갱신됩니다.

## AI 추출 (선택)

기본은 규칙 기반 추출이라 API 키 없이 동작합니다. Claude로 더 정확하게 뽑으려면 다음처럼 실행합니다.

```
pip install anthropic
set ANTHROPIC_API_KEY=sk-ant-...
python run.py --ai
```

- 공지 한 건당 한 번만 호출하고 결과를 `data/notices.json`에 저장해 다시 씁니다.
- 기본 모델은 `claude-opus-5-5`(effort low)입니다. 비용을 줄이려면 `set NOTICE_MODEL=claude-haiku-5-5`로 바꿀 수 있습니다.
- API 호출이 실패하면 그 공지는 규칙 기반 결과로 대신합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `collect.py` | 게시판 목록·본문 수집. 새 글만 받고, 최근 14일 글과 마감이 남은 글은 3시간 간격으로 다시 열어 수정·삭제를 반영. 요청 사이 0.5초 대기 |
| `extract.py` | 캠퍼스·대상·분류·마감일·할 일 추출 (규칙 / Claude) |
| `build.py` | `site/index.html`, `site/calendar/{all,seoul,global}.ics` 생성 |
| `template.html` | 화면 (필터, 브리핑, D-day, 근거 보기, 내 조건 캘린더 받기) |
| `run.py`, `run.bat` | 한 번에 실행 |

## 개인정보·운영 원칙

- 공개 게시판만 읽고, 로그인·회원가입이 없습니다.
- 사용자의 조건(캠퍼스·신분·관심)은 그 사람의 브라우저에만 저장됩니다.
- 원문 전체를 다시 게시하지 않고 요약과 원문 링크만 보여 줍니다.
- 실제 운영 전에는 수집 주기와 방식을 정보처와 협의해야 합니다.

## 알려진 한계

- 본문이 이미지뿐인 공지는 내용을 읽지 못합니다(“기한 정보 없음”으로 표시).
- 규칙 기반 추출은 근거 문장이 애매하면 `원문 확인` 표시를 붙입니다. 행사 일시가 마감일로 잡히는 경우가 있습니다.
- `calendar/*.ics` 구독 주소는 사이트를 웹에 올려야 쓸 수 있습니다. 로컬에서는 "설정한 조건의 공지 마감일을 캘린더로 받기" 버튼으로 파일을 내려받으면 됩니다.
